## PanganBerbagi

Web site ini dibuat bertujuan karena setiap tahun jutaan ton makanan terbuang sementara saudara kita membutuhkan. PanganBerbagi menjembatani resto, toko, dan donatur dengan penerima manfaat secara 100% gratis maupun skema diskon murah.

## Teknologi
- HTML5

- Tailwind CSS

- JavaScript (Modern ES6+)

- Figma

- Git & GitHub

## Tujuan Website

- Menghubungkan vendor penjual makanan berlebih dengan masyarakat atau panti sosial agar makanan layak konsumsi tidak terbuang sia-sia.

- Memberikan akses pangan murah bagi masyarakat umum (diskon 50%-70%) serta donasi gratis bagi penerima manfaat sosial.

- Mendukung pencapaian target Pembangunan Berkelanjutan global, khususnya SDG 2 (Zero Hunger / Tanpa Kelaparan) dan SDG 12 (Responsible Consumption and Production / Konsumsi dan Produksi yang Bertanggung Jawab).

## Target Pengguna

- 1. Mitra Donatur / Resto: Restoran, toko roti, katering, dan supermarket yang memiliki surplus makanan layak konsumsi.

- 2. Penerima Manfaat Sosial (Panti/Komunitas): Panti asuhan, dapur umum, dan lembaga sosial terverifikasi yang membutuhkan donasi 100% gratis.

- 3. Konsumen Umum: Masyarakat yang ingin membeli makanan surplus berkualitas dengan harga terjangkau (diskon 50%–70%).

- 4. Administrator Sistem: Pengelola platform yang bertugas memverifikasi mitra dan mengawasi alur reservasi/misi.

## Kebutuhan Sistem

Kebutuhan Fungsional

- FR-01 (Katalog Hibrida & Filter): Menyajikan katalog makanan real-time berdasarkan status harga, kategori, dan lokasi.

- FR-02 (Posting Surplus): Form bagi mitra/donatur untuk menambahkan item makanan, porsi, harga, dan batas kadaluarsa (expired).

- FR-03 (Reservasi & Tiket QR): Menghasilkan QR Code virtual unik untuk proses klaim makanan.

- FR-04 (Dashboard Rescue): Modul penugasan bagi relawan penyelamat makanan.

- FR-05 (Direktori Food Bank): Informasi titik drop-off dan kapasitas penyimpanan pangan kering.

- FR-06 (Edukasi Zero-Waste): Galeri artikel/resep interaktif pengelolaan sisa bahan dapur.

## Kebutuhan Non-Fungsional

- NFR-01 (Usability & Accessibility): Desain responsif menggunakan Tailwind CSS yang optimal diakses via smartphone maupun PC.

- NFR-02 (Performance & Speed): Waktu muat halaman cepat (< 2 detik) dengan client-side rendering.

- NFR-03 (Security & Trust): Sistem verifikasi QR Code dua arah untuk menjamin keamanan klaim.

## Cara Menjalankan

1. Unduh atau *clone* repositori:
   ```bash
   git clone [https://github.com/greenhat-77/Pangan-Berbagi.git](https://github.com/greenhat-77/Pangan-Berbagi.git)
   cd Pangan-Berbagi

2. Buka folder proyek menggunakan Visual Studio Code.

3. Jalankan index.html melalui browser favorit Anda atau gunakan ekstensi Live Server di VS Code.

4. Jelajahi berbagai modul utama PanganBerbagi (Katalog Hibrida, Form Posting Surplus, Dashboard Relawan Rescue, Food Bank, dan Edukasi Zero-Waste).

## Batasan dan Catatan Pengembangan
- Simulasi & Prototyping Front-End: Reservasi makanan surplus, generate Tiket QR Virtual, serta klaim porsi 100% Gratis saat ini berjalan di sisi client-side (halaman depan) untuk keperluan simulasi demonstrasi UI/UX antarmuka.

- Penyimpanan Data Lokal: Data reservasi, pencarian katalog, dan posting surplus dari mitra resto menggunakan alur simulasi client-side rendering tanpa integrasi database backend (seperti MariaDB/MySQL server).

- Verifikasi QR Code: QR Code virtual yang dihasilkan pada Global Modal Popup merupakan sampel visual untuk alur simulasi penyerahan pangan antara mitra resto, relawan rescue, dan penerima manfaat.

- Integrasi Peta & Logistik: Modul Food Bank dan Live Rescue Mission Cards menampilkan lokasi hub logistik pangan serta titik jemput-antar berbasis data sampel (mock data) statis.

- Penyelarasan Target SDGs: Platform ini dirancang khusus untuk mendukung pencapaian SDG 2 (Zero Hunger) dan SDG 12 (Responsible Consumption & Production) melalui alur distribusi makanan layak konsumsi.
